## 第一篇初稿

做了很多年程序员，最近越来越觉得，写代码只是工作的一部分。

真正值得长期积累的，不只是写过多少代码、完成过多少项目，还有解决问题过程中形成的判断、方法和思考。

技术发展得很快。从传统的软件开发，到云计算，再到如今的 AI 和 Agent，工具和框架不断变化。但有些问题始终值得思考：为什么采用这样的架构？复杂问题能否找到更简单的解决方式？如何判断新技术真正的价值？

很多时候，我们花了大量时间解决问题，却很少停下来整理其中的思考。时间久了，一些经验逐渐淡忘。

这也是我决定开始写「代码之外」的原因。

这里主要记录 AI 与 Agent 工程实践、软件工程与架构设计，以及程序员的技术成长与个人思考。不一定都是成熟结论，也可能是正在探索的问题。

因为代码是实现，思考才是起点。

不刻意追求更新频率，也不把每篇文章都写成教程。有实践就记录，有问题就思考，有新的认识就分享。

希望多年之后回头看，这里留下的不只是文章，还有自己对技术理解不断变化的过程。

这就是「代码之外」，一个关于技术、实践与思考的长期记录。
