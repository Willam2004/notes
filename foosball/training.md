# 训练体系

## Snake 固化训练

### 15 分钟基础结构

1. 纯 Walking / Rolling：找轻松、手腕控球的标准感觉。
2. 假出手：到中/远位置但不射，再回来。
3. 70%~80% Snake：中推、远推随机，最后横移不额外加力。
4. 比赛化：加入随机方向和关键球压力。

## 真假出手训练

`Walking → 到出手窗口 → 不射 → 回来`

与

`Walking → 到同样窗口 → 转杆射门`

要求两者在转杆之前尽可能一致。

## Rolling 位置控制训练

先不射门，随机组合四个变量：

- 距离：1/4、1/2、1、2
- 方向：左、右、连续向同一侧
- 时间：慢、快、短停、连续
- 决策：到窗口后打或不打

唯一底线：

> 距离、方向和节奏可以变，但不能靠突然增加手臂压力完成。

核心口令：

> **我不追节奏，我只控制球的位置；球到了窗口，我就转杆。**

自检优先看：

- 长步幅有没有变成用力拖球
- 连续向同一侧时位置是否仍然准确
- 决定出手后，最后横移的手感是否改变

## 读防守训练

### 录像预判

只看防守小人的脚和杆位。每次出现明确换杆时暂停：

1. 先说出换杆前的旧洞。
2. 再播放，检查自己是否抓对了离开方向。
3. 防守加快后，仍只抓换杆和重复模式，不追每个瞬间的空洞。

### 对练执行

由陪练先慢速、再逐渐加快换杆，自己保持正常 Rolling：

`看到换杆 → 记住旧洞 → 球自然滚进对应窗口 → 转杆`

成功标准：

- 第一观察信号是换杆，而不是已经出现的空洞
- 选定旧洞后没有突然加力
- 球没有到位时不补力、不抢打

## 压力训练

每组 5 球，把第 5 球当作 4:4 关键球。

成功标准优先看：

- 最后横移有没有突然加力
- 身体有没有额外预动作
- 手腕控球感有没有丢失

而不是只看进球率。

## 单打综合训练

完整链路：

`后卫控球 → 2传5 → 5杆接球 → 3杆 → Walking / Rolling → Snake`

最后一段训练不纠动作，只模拟比赛执行。
