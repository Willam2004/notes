# 比赛防守阅读策略

## 核心口令

> 不急着挡，先看一个点。

面对高手连续进球时，不要求下一球必须挡住。每次只读取一个信息，然后验证。

## 三球阅读法：时 → 触 → 向 → 变

### 1. 时：什么时候打？
第一球先不猜洞，只观察对方的出手时间：是快速出手、Walking/Rolling 几次后出手，还是等待我先动。

### 2. 触：什么触发他出手？
这是最重要的一步。只问：我刚才做了什么，他就打了？

重点观察：
- 我换杆，他出手？
- 我停住，他出手？
- 我移动到某个位置，他出手？
- 我回位，他出手？

### 3. 向：触发以后打哪里？
有了时间和触发点以后，再观察方向：推、拉、中路，以及近洞、远洞。

例如：等我换杆 → 换杆后出手 → 经常远拉。

### 4. 变：主动验证
读到模式以后再改变。可以延迟换杆、提前换杆、假换杆、换杆后快速回位，或者改变停顿时间，观察对方是否仍按原模式出手。

## 比赛纪律

> 读 → 再变，而不是丢 → 就变。

没有明确读到信息前，同一套基础防守尽量观察 2～3 球。不要因为连续被进就每球大改，否则自己一直改变条件，反而读不出对手。

连续失分时，不问“为什么又没挡住”，改问：这几个球让我知道了什么？

## 比赛现场极简版

> 时 → 触 → 向 → 变

- 时：什么时候打？
- 触：我什么动作触发他？
- 向：触发以后打哪里？
- 变：我怎么改变这个触发点？

其中最优先观察：**我的哪个动作触发了他的出手？**

## 与复盘体系结合

这套方法属于“技—读—变—稳”中的“读 → 变”：

稳定基础防守 → 读（时/触/向）→ 变（改变触发条件）→ 再观察。

赛后固定复盘三个问题：
1. 我看到了他的出手时间吗？
2. 我的哪个动作触发了他的出手？
3. 这个触发以后，他最常打哪里？
