# 心理与关键球

## 关键球原则

关键球不是要做一个更强、更快的动作，而是不要破坏平时已经形成的动作。

Snake 关键球常见问题：

`想到必须打进 → 决定远推/远拉 → 手腕和前臂突然变紧 → 横移加力 → 动作变形`

核心处理：

> **松，手腕带球。**

或：

> **让球滚到位置，我只负责转。**

## 固定流程

关键球时使用固定流程降低临时思考：

`呼气 → 放松 → 正常 Walking / Rolling → 球进入窗口 → 转杆`

不要因为比分重要而主动提速或增加横向压力。

## 领先心理

大比分领先后：

> **比分归零，观察重启。**

重新读取对手，而不是开始保护比分。
