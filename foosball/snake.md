# Snake 技术体系

## 1. 当前核心模型

Snake 的射门不是靠“决定射门后突然增加横向压力”，把球强行推/拉到目标位置。

正确动作逻辑：

> Walking / Rolling 负责控球、节奏和位置；保持相近的控球压力让球进入出手窗口；真正的爆发留给转杆击球。

动作链：

`Walking / Rolling → 球自然滚动 → 进入推/拉/中洞出手窗口 → 转杆爆发`

避免：

`Walking / Rolling → 决定推/拉 → 前臂/肩膀突然加力拖球 → 位置变化 → 再转杆`

## 2. 三条核心口令

- **方向由滚动决定，力量由转杆产生。**
- **晃移同力，转杆爆发。**
- **手腕带球，节奏自由；出手不变手感，只变转杆。**

比赛中可简化为：

> **让球滚到位置，我只负责转。**

## 3. 手腕控球

目标是从“手臂推着球走”转向“手腕感知并带着球走”。

理想状态：

`假动作时的手腕感觉 = Walking 时的手腕感觉 = 出手前最后横移的手腕感觉`

决定射门本身不能成为新的发力信号。即使已经决定推、拉或中洞，也只是选定目标窗口，不能改变带球方式：

`选定窗口 → 继续原来的 Walking / Rolling → 球到位 → 转杆`

预判只决定球去哪里，不决定手臂怎么发力。

## 4. Walking / Rolling 与步幅

Walking 不必固定为同一幅度，可以使用不同步幅组合：

- 1/4
- 1/2
- 1
- 2

并与时间节奏结合：

- 慢
- 快
- 停留
- 连续
- Rolling

步幅和节奏都可以变化，但控球压力不应因此突然变重。

最终目标：

- 1/4 可以打，也可以不打
- 1/2 可以打，也可以不打
- 1 可以打，也可以不打
- 2 可以打，也可以不打
- 慢可以打，也可以不打
- 快可以打，也可以不打
- Rolling 可以打，也可以不打
- Walking 可以打，也可以不打

## 5. 推 / 拉统一原则

推和拉不应形成两套完全不同的发力逻辑。

正确统一模型：

`手腕控球 → 球滚到对应出手窗口 → 转杆`

远推、远拉不等于“需要更大的横向力量”，只是“球需要进入更远的出手窗口”。

常见错误：

- 想到远推后，前臂主动送杆
- 想到远拉后，手臂突然发力拽球
- 为了追求力量，肩膀、肘和身体出现明显预动作
- 最后一拍横移与普通 Walking 明显不同

## 6. 稳定性的关键

稳定射门的关键之一是：

> Walking / Rolling 时对球的横向控制力度，与真正击打前最后一段横移保持相近。

不是整个动作力量都一样。真正的明显爆发应该发生在转杆击球阶段。

可以理解为：

`晃动 3 → 晃动 3 → 最后横移 3~4 → 转杆 9`

避免：

`晃动 3 → 晃动 3 → 决定远洞 → 横推/横拉 8 → 转杆 9`

## 7. Rolling 的四个自由度

Rolling 不只是固定的左右往返，而是在四个维度上自由变化：

- 距离：1/4、1/2、1、2
- 方向：左、右、连续向同一侧
- 时间：慢、快、短停、连续
- 决策：打或不打

可以突然变长、变短，也可以连续偏向一侧。所有变化都服务于把球准确带到指定位置，而不是追求某一种固定节奏。

核心口令：

> **我不追节奏，我只控制球的位置；球到了窗口，我就转杆。**

“突然变长”是滚动距离变长，不是突然加力拖球：

> 距离、方向、时间和真假可以变，控球压力不变。

## 8. 假动作

假动作不是额外做一个大动作，而是利用本来就存在的控球自由度：

- 不同步幅
- 快慢切换
- Rolling / Walking 切换
- 到出手窗口后不打，再回来

真正高质量的假动作要求：

> 真出手和假出手，在转杆发生之前尽可能相似。

## 9. 关键球

比赛紧张时最容易出现：

`想到洞位 → 手腕/前臂变紧 → 横移突然加力 → 身体预动作增大 → 击球窗口改变 → 稳定性下降`

关键球口令：

> **松，手腕带球。**

或：

> **让球滚到位置，我只负责转。**

目标不是关键球做出更强的 Snake，而是关键球不破坏平时已经有的 Snake。

## 10. 当前训练重点

1. 最后一次横移保持普通 Walking 的手感。
2. 推拉两侧都统一到“球滚到位，再转杆”。
3. 长短、左右、同侧连续都能随机组合，并能直接出手或不出手。
4. 压力下保持同样的手腕控球感。
5. 动作稳定后再提高极限横移速度和转杆速度。

## 11. 实战案例：单洞锁定与窗口捕捉（2026-10-14）

- 比赛：Kia Wee Lim VS Abbas Babapour | OS Semi-Final | 2025 Taiwan Foosball Open
- 视频：https://b23.tv/KjCCONu
- 重点：第五局（用户观察；未逐帧核验或统计射门次数）

### 观察

用户注意到 Snake 进攻方反复选择拉边：防守杆持续晃动，拉边窗口一出现就尝试出手，而不是每次重新选择推、拉、中路。这属于“锁定目标洞位、等待窗口”的战术思路。不能据此断言第五局所有射门都打拉边，也不能仅凭观察确定选手的主观意图。

### 技术理解

- **方向先定，时机后定**：减少临场方向选择，将注意力集中在目标窗口及防守杆移动。
- **看防守离开目标线的过程**：不仅看静态空洞，还看移动方向和可能的回防时间。
- **同一落点可以有不同出手时间**：固定拉边不代表固定节奏。
- **不强打关闭的洞**：如果对手持续封住拉边，仍需保留切换中路、推边的能力。
- **不破坏控球动作**：窗口出现时沿用正常 Walking / Rolling 手感，让球到位后转杆；避免突然加压拖球。

### 专项训练：拉边窗口捕捉（10分钟）

1. 2分钟：无防守，拉边到位直接转杆，保证不二次调整。
2. 4分钟：搭档随机移动防守杆，只观察拉边；窗口有效才出手，错过则继续控球。
3. 4分钟：搭档随机改变移动速度，练习放弃过短窗口、捕捉可完成射门的窗口。
4. 记录20次机会中的有效窗口识别、实际出手和命中数；不要为追求次数强行射门。

**口令：锁定拉边，看杆离开；球到窗口，直接转杆。**
